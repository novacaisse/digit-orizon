# Prompts d'illustrations — Digitorizon

10 illustrations à générer (ChatGPT/DALL·E, Midjourney ou équivalent), pour
remplacer les icônes génériques actuelles par de vraies illustrations sur le
site. Chaque prompt ci-dessous est autonome : copie-colle tout le bloc
(description + format + style) directement dans l'outil de génération, sans
rien ajouter. Une fois les 10 images générées, envoie-les-moi (nom de
fichier au choix, précise juste le numéro si ce n'est pas clair) et je les
intègre aux bons endroits sur le site.
