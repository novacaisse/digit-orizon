# Prompts d'illustrations — Digitorizon

10 illustrations à générer (ChatGPT/DALL·E, Midjourney ou équivalent), pour
remplacer les icônes génériques actuelles par de vraies illustrations sur le
site. Envoie-moi les 10 images une fois générées (nom de fichier au choix,
je les intègre aux bons endroits).

## Style commun — à coller à la fin de CHAQUE prompt

Copie-colle ce bloc à la suite de chaque prompt ci-dessous, pour garantir que
les 10 images se ressemblent visuellement :

```
Style : illustration numérique moderne et professionnelle, formes légèrement
arrondies, dégradés doux, éclairage chaleureux, esthétique haut de gamme
type SaaS/tech (pas de style cartoon enfantin, pas de clipart générique).
Palette dominante : orange chaud (#F7941D), bleu ciel (#29ABE2), touches de
noir profond (#12100E), fond clair neutre ou dégradé doux (#FAF9F7).
Aucun texte, aucune lettre, aucun chiffre, aucun logo dans l'image.
Si des personnages sont représentés, ce sont des Ivoiriens/Ivoiriennes,
traits et carnation réalistes, tenues professionnelles contemporaines
africaines. Haute résolution, sans filigrane, sans bordure.
```

## Format recommandé

- Images "hero" et "grande illustration" : format 4:3 (ex. 1600×1200)
- Toutes en PNG, fond qui se marie avec un fond clair (évite le fond blanc
  pur si possible, préfère un léger dégradé ou une scène qui respire)
