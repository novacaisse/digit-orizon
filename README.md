# Digi Horizon Launchpad

Crée un site web vitrine professionnel pour **Digitorizon**, une agence web basée en Côte d'Ivoire, spécialisée dans la création de sites internet sur-mesure. Le site doit fonctionner comme un véritable outil commercial : clair, crédible, rassurant, et optimisé pour convertir les visiteurs en demandes de devis.

Les logo ci joint , et aussi le logo de Digitorizon ci joint ( prête attention)

**Contraintes techniques**

- Site 100% frontend, **sans base de données**

- Formulaire de contact/devis connecté à Formspree : `https://formspree.io/f/xvzewokk` (méthode POST standard HTML ou fetch)

- Site ultra rapide, léger, optimisé (lazy loading images, compression, pas de librairies inutiles)

- 100% responsive (mobile-first), testé mobile/tablette/desktop

- Un seul langage : one-page avec navigation par ancres + scroll fluide (smooth scroll)

- Ne pose aucune question : prends toutes les décisions de contenu manquantes en cohérence avec ce brief et livre un site complet, fonctionnel, prêt à l'emploi



**Ne me pose pas de questions** — si une information manque, déduis-la intelligemment du contexte (agence web professionnelle, Côte d'Ivoire, clé en main) et complète toi-même.

**Logo** : fichier fourni en pièce jointe (Digitorizon — dégradé orange/gris/bleu en arc, texte "Digi" orange + "torizon" avec un soleil doré). Utilise-le :

- Dans le header (taille adaptée, cliquable → retour hero)

- Dans le footer

**Palette de couleurs** (extraite du logo)

- Orange principal : `#F7941D`

- Bleu principal : `#2E9BD6`

- Doré/Ambre (accent) : `#F5B942`

- Anthracite (textes forts, section sombre) : `#1A1D23`

- Blanc cassé (fond principal) : `#FAFAFA`



**Typographie**

- Titres : police display moderne et impactante (ex : Sora, Space Grotesk ou Manrope, en Bold/ExtraBold)

- Texte courant : police lisible (ex : Inter)

- Titres H1 très grands sur desktop (impact visuel fort), hiérarchie claire H1 > H2 > H3



**Style général — le design doit être REMARQUABLE, pas générique**

- Fond clair général avec **une section en fond sombre anthracite** au milieu du parcours (ex: section "Processus") pour créer du rythme et un effet premium

- Dégradé animé subtil (orange → gris → bleu, reprenant l'arc du logo) en arrière-plan du Hero

- Beaucoup d'espace blanc, mise en page aérée, pas surchargée

- Micro-interactions sur tous les boutons (hover avec léger glow orange/bleu, effet de lift/scale sur les cartes au survol)

- Animations d'apparition au scroll (fade-up léger sur chaque section, sans ralentir le chargement)

- Compteurs animés pour les chiffres clés (ex: "100+" qui s'anime au scroll)

- Réalisations présentées dans des mockups de type navigateur/téléphone, avec légère rotation 3D au survol

- Bouton CTA flottant sticky (bas droite) "Devis gratuit", visible sur toutes les sections après le hero

- Grille asymétrique par endroits pour éviter l'effet "template" trop symétrique



**Images**

- Le site a besoin d'images professionnelles (hero, illustrations de sections, visuels d'accompagnement). Génère des images de haute qualité, professionnelles, en cohérence avec un univers "agence web / tech / digital moderne" et avec la palette orange/bleu/doré du site — évite les banques d'images génériques ou clichées, privilégie un style moderne, épuré, professionnel, cohérent avec une agence premium

- Pour la section Réalisations, utilise des mockups (frames navigateur/mobile) plutôt que des captures brutes

## SEO — OBLIGATOIRE



- Balise `<title>` optimisée : "Digitorizon — Création de site web professionnel clé en main en Côte d'Ivoire"

- Meta description optimisée (150-160 caractères) intégrant "création de site web", "Côte d'Ivoire", "devis gratuit"

- Balises Open Graph complètes (og:title, og:description, og:image avec le logo, og:type, og:url) pour un bon rendu au partage sur les réseaux sociaux

- Balises Twitter Card

- Structure Hn cohérente et unique (un seul H1 sur la page = le titre du hero)

- Attributs `alt` descriptifs et pertinents sur toutes les images (incluant mots-clés naturels : "création site web Côte d'Ivoire", etc.)

- URLs d'ancres propres pour la navigation interne

- Fichier `sitemap.xml` et `robots.txt` générés

- Données structurées Schema.org de type `Organization` / `LocalBusiness` avec les coordonnées (email, téléphone, réseaux sociaux)

- Favicon généré à partir du logo, décliné dans les différentes tailles nécessaires (16x16, 32x32, apple-touch-icon)

- Vitesse de chargement optimisée : compression d'images, lazy loading, pas de scripts bloquants
